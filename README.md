# tenzerothree.github.io

Personal portfolio site for Chris Ward — UI/UX designer and frontend developer based in Cambridge, UK.

Built as a simple static page that does the job without any framework overhead.

## Features

- Career timeline covering freelance, SyndicateRoom, and Risilience
- Case study pages for featured client work
- Contact section with email, phone, and social links

## Usage

Open `index.html` in a browser. No build step required.
